# 🎭 Adivina el Personaje

Juego interactivo donde debes adivinar personajes famosos basándote en pistas visuales.

## 🎮 Cómo Jugar

1. Observa la imagen del personaje
2. Lee la pista
3. Escribe el nombre del personaje
4. ¡Presiona Enter o el botón para adivinar!

## 🚀 Demo en Vivo

[Jugar Ahora](https://tu-usuario.github.io/adivina-personaje/)

## 🛠️ Tecnologías

- HTML5
- CSS3 (Animaciones y Gradientes)
- JavaScript Vanilla

## 📝 Características

- ✅ 5 niveles con personajes famosos
- ✅ Sistema de intentos
- ✅ Barra de progreso
- ✅ Animaciones suaves
- ✅ Responsive design
- ✅ Estadísticas finales

## 🎨 Personalización

Puedes agregar tus propios personajes editando el array `personajes` en el archivo `index.html`:

\`\`\`javascript
const personajes = [
    {
        nombre: "tu-personaje",
        pista: "Tu pista aquí",
        imagen: "URL de la imagen"
    }
];
\`\`\`
